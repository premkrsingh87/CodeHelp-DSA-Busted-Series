📖 How this works & first-time setup (click to expand)

1 · Why a proxy copy?

A browser cannot scrub a YouTube video frame-by-frame — YouTube blocks it. So the bridge grabs a throwaway 240p copy (a few MB) that can be scrubbed, filmstripped and analysed. You pick your moments on that. The clips you export are then pulled fresh from YouTube at full quality, only the exact seconds you marked.

2 · Start the bridge

cd clipforge-pro/bridge # Windows start_bridge.bat # macOS / Linux ./start_bridge.sh

Leave that window open. The chip in the header turns green.

3 · No bridge? Still works

Use Get proxy download script to grab the 240p copies with one .bat, then drop the files back in. Or switch the preview to the YouTube embed — you lose the filmstrip and auto-detect, but marking and exporting work exactly the same.

🔌 Local bridge setup

The bridge is a small Python script that runs on your own machine. It uses yt-dlp to fetch the low-res proxy copies and to pull your final clips. Nothing is uploaded anywhere — everything stays local.

1
Save the bridge script (or use the copy in clipforge-pro/bridge/)
2
Install yt-dlp once, then run the bridge
pip install -U yt-dlp python clipforge_bridge.py

FFmpeg is optional but recommended — it merges audio and makes the cuts land exactly on your marks.

3
Come back here — the header chip turns green and proxies download automatically.

Don't want to install anything? Everything except automatic proxies and one-click extraction still works. Use Get proxy download script for a .bat that fetches the 240p copies, or preview with the YouTube embed and export the .bat script as usual.
